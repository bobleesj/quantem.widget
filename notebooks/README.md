# Notebook examples

The maintained, interactive documentation notebooks live in
[`docs/tutorials/`](../docs/tutorials/). Start with the
[demo route](../docs/tutorials/demo.md) for crystal inspection, acquisition
planning, and volume review, or [Show4DSTEM](../docs/tutorials/show4dstem.ipynb)
for measured scan data.

The short examples under this directory are older, supplementary entry points.
They are not the canonical documentation or the validated crystal-to-volume
demo sequence. Add or revise public tutorials under `docs/tutorials/` so the
notebook and documentation site share one source.

Keep those source notebooks interactive. Execute copies for local review;
the documentation build executes the canonical notebooks and embeds widget
state in the resulting pages. Do not replace the source notebooks with static
GitHub previews or commit generated widget state.
